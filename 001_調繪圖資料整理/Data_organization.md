# Data_organization.py

## 功能概述

具有 GUI 介面的自動資料整理工具，將掃描圖（JPG）、定位檔（JGW）、調繪照片，依分幅號自動分類歸檔至目標資料夾，並支援設定記憶（config.ini）。

---

## GUI 操作說明

| 欄位 | 說明 |
|------|------|
| 1. 掃描檔資料夾 | JPG 掃描圖的來源，可多選（`;` 分隔） |
| 2. 定位檔資料夾 | JGW 定位檔的來源，可多選 |
| 3. 調繪照片資料夾 | 調繪照片 JPG 的來源，可多選 |
| 4. 輸出目標資料夾 | 整理後的統一存放位置（單選） |
| 搜尋深度 | 所有子資料夾 / 僅當前 / 指定 N 層 |

---

## 處理流程

```
步驟一：掃描檔
  找出符合「XXXX-YY.jpg」格式的 JPG
  → 建立 {目標}/{分幅號}/初調掃描/ 並複製

步驟二/三：定位檔
  嚴格配對（.jgw 的主檔名須與已處理的掃描檔一致）
  → 複製至對應 初調掃描/ 資料夾

步驟四：調繪照片
  在各照片來源中搜尋名為分幅號的子資料夾
  → 複製 JPG 至 {分幅號}/初調照片/
  → 若無照片，資料夾名稱加上後綴 __無
```

---

## 檔名分幅號判斷規則（`get_classification_name`）

| 檔名格式 | 分幅號 |
|----------|--------|
| `XXXX-YY.jpg` | `-` 前的部分（XXXX） |
| `YYYYZZ...jpg`（前4碼為數字） | 前 4 碼 |

---

## 內部常數

| 常數 | 預設值 | 說明 |
|------|--------|------|
| `FOLDER_SCAN_IMAGES` | `"初調掃描"` | 掃描圖子資料夾名稱 |
| `FOLDER_ADJUSTED_PHOTOS` | `"初調照片"` | 照片子資料夾名稱 |
| `SUFFIX_NO_PHOTOS` | `"__無"` | 無照片分幅的後綴 |

---

## 設定記憶

路徑與深度設定自動儲存至執行目錄下的 `config.ini`，下次開啟自動載入。
