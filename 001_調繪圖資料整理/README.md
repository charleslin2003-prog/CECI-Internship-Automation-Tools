# Data_Organizer_GUI.py

## 一、功能概述

具 GUI 介面的調繪圖資料自動整理工具。依「分幅號」自動將掃描圖（JPG）、定位檔（JGW）與調繪照片分類歸檔至目標資料夾，並以 `config.ini` 記憶上次設定。背景執行緒處理，附即時 log。

---

## 二、依賴套件

| 套件 | 用途 |
|------|------|
| `tkinter` | GUI 介面（標準庫） |
| `os` / `shutil` | 路徑操作、檔案複製（標準庫） |
| `configparser` | 設定檔讀寫（標準庫） |
| `threading` | 背景執行緒（標準庫） |
| `re` | 搜尋深度字串解析（標準庫） |

> 全為 Python 標準庫，無第三方相依，可直接以 PyInstaller 打包為 exe。

---

## 三、GUI 操作欄位

| 欄位 | 說明 |
|------|------|
| 1. 掃描檔資料夾 | JPG 掃描圖來源，可多選（`;` 分隔） |
| 2. 定位檔資料夾 | JGW 定位檔來源，可多選 |
| 3. 調繪照片來源資料夾 | 調繪照片 JPG 來源，可多選 |
| 4. 最終輸出目標資料夾 | 整理後統一存放位置（單選） |
| 搜尋深度設定 | 所有子資料夾 / 僅當前資料夾 / 指定 1～10 層 |

---

## 四、處理流程

```
步驟一：處理掃描檔（.jpg）
  找出符合「XXXX-YY.jpg」格式（主檔名以單一 '-' 分為兩段）的 JPG
  → 建立 {目標}/{分幅號}/初調掃描/ 並 copy2 複製

步驟二／三：處理定位檔（.jgw）
  嚴格配對：.jgw 主檔名須與已處理的掃描檔主檔名一致才複製
  → 複製至對應 {分幅號}/初調掃描/

步驟四：處理調繪照片
  於各照片來源中搜尋「名稱等於分幅號」的子資料夾
  → 複製其中 JPG 至 {分幅號}/初調照片/
  → 若該分幅查無照片，資料夾改名加後綴「__無」
```

---

## 五、分幅號判斷規則（`get_classification_name`）

| 檔名格式 | 取得的分幅號 |
|----------|--------------|
| `XXXX-YY.ext` | `-` 之前的字串（XXXX） |
| 前 4 碼為數字 | 前 4 碼 |
| 其他 | 無（略過） |

---

## 六、輸出資料夾結構

```
{目標}/
├── {分幅號}/
│   ├── 初調掃描/   ← .jpg 掃描圖 + .jgw 定位檔
│   └── 初調照片/   ← 調繪 .jpg 照片
└── {分幅號}__無/   ← 查無調繪照片之分幅
```

---

## 七、內部常數

| 常數 | 預設值 | 說明 |
|------|--------|------|
| `FOLDER_SCAN_IMAGES` | `"初調掃描"` | 掃描圖子資料夾名稱 |
| `FOLDER_ADJUSTED_PHOTOS` | `"初調照片"` | 照片子資料夾名稱 |
| `SUFFIX_NO_PHOTOS` | `"__無"` | 無照片分幅的後綴 |
| `EXT_JGW` | `".jgw"` | 定位檔副檔名 |
| `EXT_JPG` | `[".jpg", ".jpeg"]` | 影像副檔名 |

---

## 八、注意事項

- 路徑與深度設定自動儲存於執行目錄下的 `config.ini`，下次開啟自動載入。
- 複製採 `shutil.copy2`，保留檔案時間戳；不刪除原始檔。
- 掃描檔配對採嚴格規則，主檔名不一致的 JGW 不會被歸檔。
- 1～4 項路徑皆須選擇，否則不執行。
- 打包為 exe 後，`config.ini` 會與執行檔同目錄。
