# metashapeXML2IPF.py

## 一、功能概述

將 Metashape 輸出的 XML（含連接點與控制點）轉換為航測平差軟體所需的 IPF 格式。包含邊緣緩衝剔除、3×3 九宮格選點、不足時補點補償，以及選點 / 補點統計報告。

---

## 二、依賴套件

| 套件 | 用途 |
|------|------|
| `xml.etree.ElementTree` | `iterparse` 逐節點解析 XML（標準庫） |
| `pandas` | 選點統計報告 |
| `collections.defaultdict` | 影像 ↔ 點位對應表（標準庫） |
| `pathlib` / `os` / `time` | 路徑、計時（標準庫） |

---

## 三、主要模組

### 1. 解析模組 `parse_metashape_xml()`

- 以 `iterparse` 逐節點讀取，避免大檔記憶體爆炸（處理完即 `elem.clear()`）。
- 依影像尺寸（寬 × 高）查表 `KNOWN_CAMERAS` 自動判斷像元大小（ps）。
- 分別解析：照片清單（Photo）、連接點（TiePoint）、控制點（ControlPoint）。

**相機規格表（可擴充 `KNOWN_CAMERAS`）**

| 影像尺寸（寬 × 高） | 像元大小 (mm) |
|---|---|
| 14592 × 25728 | 0.0039 |
| 20544 × 14016 | 0.00376 |
| 11310 × 17310 | 0.006 |

### 2. 選點模組 `select_tie_points_optimized()`

```
對每張影像：
  ① 剔除邊緣 buffer_ratio（預設 5%）區域內的點
  ② 將剩餘點投入 3×3 九宮格
  ③ 每格依「共視影像數↓、距格心距離↑」排序，取前 pts_per_cell 點（預設 2）
  ④ 若總選點 < 18（pts_per_cell × 9），從有效點中依共視數補足
  ⑤ 記錄每張影像選點數與補點數
```

| 參數 | 預設 | 說明 |
|------|------|------|
| `pts_per_cell` | `2` | 每格選點數 |
| `buffer_ratio` | `0.05` | 邊緣剔除比例（5%） |
| 目標點數 | `18` | `pts_per_cell × 9` |

### 3. 輸出模組 `export_ipf_files()`

- 控制點在前、連接點在後（`cps + tps`）。
- 連接點流水號重編，依總數補零對齊。
- 座標轉換：像素座標 → 以影像中心為原點的影像座標系（mm）。
- 每張影像輸出對應一個 `.ipf` 文字檔（無選點則略過）。

**IPF 欄位**

```
pt_id, val, fid_val, no_obs, l., s., sig_l, sig_s, res_l, res_s, fid_x, fid_y
```

## 四、路徑設定

```python
XML_INPUT  = r"路徑\input.xml"   # XML 輸入路徑
OUT_FOLDER = r"成果"             # IPF 成果輸出路徑
```

---

## 五、執行後輸出

- 各影像對應的 `.ipf` 檔案。
- 終端機報告：平均選點數、最低點數影像、觸發補點機制的影像清單（檔名、補點數、最終點數）、總耗時。

---

## 六、注意事項

- 新增相機型號須先在 `KNOWN_CAMERAS` 登錄「尺寸 → 像元大小」，否則該影像 ps 取 `default_ps`（0.0039）。
- 邊緣 5% 剔除用於降低鏡頭畸變影響；補點機制確保每張影像盡量達到 18 點。
- XML 以 `{*}` 命名空間萬用解析，相容不同版本標籤前綴。
