# 控制點萃取工具 — 執行流程說明

---

## 1. 讀取資料

程式啟動後，依序讀取三個輸入檔案：

- AI 偵測點 SHP
- 人工量測點 SHP
- 測區面資料 SHP（可選，用於計算基準面積與 ROI 稀疏報告）

---

## 2. PT 欄位偵測與配對模式判斷

讀取完成後，程式自動偵測兩個點位 SHP 是否含有 PT 欄位（欄位名稱可透過 `PT_FIELD` 參數修改，預設為 `"PT"`）。

**偵測結果分三種情況：**

### 情況 A：雙邊皆有 PT 欄位且有值

詢問使用者是否將 PT 欄位作為控制點配對編號：

- **選 Y** → 進入 PT 模式
- **選 N** → 進入自動模式

### 情況 B：單邊有 PT 欄位

印出警告（說明哪一側缺少），直接進入自動模式，不詢問。

### 情況 C：兩側皆無 PT 欄位

直接進入自動模式，不詢問。

---

## 3. 配對執行

### PT 模式（`_match_by_pt`）

取兩側 PT 值的交集，以相同 PT 值強制配對，配對距離固定記為 0.0。PT 配對完成後，進入補點詢問（見第 4 節）。

### 自動模式（`_match_auto`）

1. 排除已配對的 AI 點與人工點
2. 對剩餘人工點做**孤立點篩選**（距離其他人工點 > `ISOLATION_DIST`）
3. 每個孤立人工點找最近 AI 點，距離 ≤ `MAX_MATCH_DIST` 才列為候選
4. **雙向一對一去重**：同一 AI 點被多個人工點選中時保留距離最短者，同一人工點亦不重複出現
5. 配對完成，直接進入流水號編號（略過補點流程）

---

## 4. 補點流程（PT 模式後）

PT 配對完成後，詢問是否補充剩餘控制點：

- **選 N** → 略過補點，直接進行流水號編號
- **選 Y** → 執行兩階段補點

---

### 第一輪：孤立點篩選補點（批次）

1. 排除已被 PT 配對用掉的 AI 點與人工點
2. 對剩餘人工點執行孤立點篩選（同自動模式邏輯）
3. 最近鄰配對 + 雙向去重
4. 通過篩選的配對全部批次補入

**第一輪結束後執行均勻度檢查：**

- 計算當前所有控制點的 Voronoi 圖
- 若最大 Voronoi cell 面積 < 基準面積 / 控制點數 × `VORONOI_STOP_RATIO` → 視為均勻，略過第二輪

---

### 第二輪：Voronoi 迭代補點（逐輪）

均勻度不足時進入第二輪，以迭代方式逐輪補點，每輪步驟如下：

**步驟 1** — 計算當前所有控制點的 Voronoi 圖，找出面積最大的 cell（最稀疏區域）

**步驟 2** — 對全域剩餘人工點執行孤立點篩選

**步驟 3** — 對篩選後的孤立點排序：落在最大 cell 內的優先，其餘依原順序排列

**步驟 4** — 依排序批次配對（最近鄰 + 雙向去重），補入本輪結果

完成一輪後，重新計算 Voronoi 並進入下一輪。

**停止條件（任一觸發即停止）：**

| 條件 | 說明 |
|------|------|
| 分佈已均勻 | 最大 Voronoi cell < 基準面積 / 控制點數 × `VORONOI_STOP_RATIO` |
| 候選人工點用完 | 剩餘未配對人工點為零 |
| 無孤立候選點 | 剩餘人工點全為密集點，孤立點篩選後為空 |
| 無可配對候選點 | 所有孤立候選點距離最近 AI 點均超過 `MAX_MATCH_DIST` |

---

## 5. 流水號編號（`_assign_match_id`）

所有配對（PT 配對 + 補點）合併後，統一從 1 開始依序編號，寫入 `match_id` 欄位。

---

## 6. 分佈摘要輸出

流水號編號完成後，印出以下資訊：

- 控制點總數
- 基準面積（優先使用測區面資料總面積，否則用控制點凸包面積）
- 平均負責面積（基準面積 / 控制點數）
- 最大 Voronoi cell 面積及其與平均的倍率
- 若倍率超過 `VORONOI_STOP_RATIO`，印出警告

---

## 7. 配對數量檢查

若最終配對數量為 0，程式自動在兩個 SHP 中新增空白 PT 欄位並儲存，提示使用者於 QGIS / ArcGIS 中手動填寫後重新執行，程式結束。

---

## 8. 輸出 SHP

配對數量 > 0 時，依序輸出三個 SHP：

**`control_point_lines.shp`**
每組配對輸出一條連線（AI 點 → 人工點），屬性含 `match_id`、`dist_m`。

**`AI_ctrl_points_matchid.shp`**
AI 控制點，保留原始所有屬性欄位，新增：

| 欄位 | 說明 |
|------|------|
| `match_id` | 配對流水號 |
| `X_new` | 對應人工點 X 座標 |
| `Y_new` | 對應人工點 Y 座標 |
| `dx` | 人工點 X − AI 點 X |
| `dy` | 人工點 Y − AI 點 Y |

**`Manual_ctrl_points_matchid.shp`**
人工控制點，保留原始所有屬性欄位，新增 `match_id`。

---

## 9. 輸出 xlsx

輸出一個含兩個 Sheet 的 xlsx 檔：

**Sheet 1：補點記錄**

每筆補點記錄一列，欄位含輪次、迭代次數、方法、人工點座標、AI 點座標、配對距離。無補點時寫入「無補點記錄」說明列。

**Sheet 2：ROI 稀疏報告**

需提供 `SURVEY_SHP_PATH` 才能產生。每個 ROI 一列，欄位含控制點數、ROI 面積、密度，以及兩個警告標記：

| 標記欄位 | 觸發條件 |
|----------|----------|
| `最大cell所在ROI` | 最終 Voronoi 最大 cell 的中心點落在此 ROI |
| `密度低於全域平均` | 該 ROI 控制點密度低於全測區平均密度 |

未提供面資料時，寫入「未提供測區面資料，無法產生報告」說明列。

---

## 流程總覽

```
讀取資料
  └─ PT 欄位偵測
       ├─ 雙邊有值 → 詢問 Y/N
       │    ├─ Y → PT 配對 → 詢問補點
       │    │         ├─ N → 流水號編號
       │    │         └─ Y → 第一輪孤立點補點
       │    │                   └─ 均勻？
       │    │                       ├─ YES → 流水號編號
       │    │                       └─ NO  → 第二輪 Voronoi 迭代
       │    │                                  └─ 停止條件 → 流水號編號
       │    └─ N → 自動配對 → 流水號編號
       ├─ 單邊有值 → 警告 → 自動配對 → 流水號編號
       └─ 無 PT   → 自動配對 → 流水號編號

流水號編號 → 分佈摘要
  └─ pairs = 0？
       ├─ YES → 新增 PT 欄位 → 結束
       └─ NO  → 輸出 SHP → 輸出 xlsx → 完成
```
